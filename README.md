# Moved into agent-link

This Paseo plugin now lives inside the [**agent-link**](https://github.com/itsjustanks/agent-link) repository, under [`paseo-plugin/`](https://github.com/itsjustanks/agent-link/tree/main/paseo-plugin) — the CLI and the panel are released together, so they share one repo.

Install it with:

```sh
agent-link plugin install
```

This repository is archived and no longer updated.
